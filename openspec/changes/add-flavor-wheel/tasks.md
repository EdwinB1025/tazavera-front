# Tasks

Every numbered task is one commit, in order. Odd tasks are `test(feedback): …` commits whose only allowed failures are the behaviour or module the next task adds (failing tests and typecheck errors for its missing modules or exports); even tasks are the `feat(feedback): …` (or `refactor(feedback): …`) commit that makes everything pass. The task's checkbox is checked in the same commit that completes it. The commit scope is `feedback` (the change's capability) even where a task touches `entities/taxonomy`. Nothing under `src/shared/api/schema.ts`, `contracts/openapi.yaml`, `messages/` or `openspec/` (beyond checking off these boxes) is ever touched.
