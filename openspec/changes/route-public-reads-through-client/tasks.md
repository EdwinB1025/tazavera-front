# Tasks

## 1. Route the public reads through `publicRequest`

Each task replaces a hand-built `` `${process.env.NEXT_PUBLIC_API_URL}<path>` `` plus `fetch` with `publicRequest(<path>, init?)`, updating the module comments that describe the plain `fetch` against `NEXT_PUBLIC_API_URL`, and keeping the path and query string, the request options (passed as `init` unchanged), the status check, the parsing and the result shape. No test is added and no assertion changes; a mock of `@/shared/api` that lacks `publicRequest` and breaks may gain it (import change, stated in the commit body). If a protecting test fails only because of the call's argument list or an unset environment value, stop and report it.
