# Tasks

Each group is a vertical slice; its heading names the commit scope. Tests are committed before the implementation they cover. Each test task names the only tests to write: one test per spec scenario it lists (AGENTS.md "Testing"), no extra cases; a scenario already covered by a shared component's tests or by the final browser check is named as such and gets no new test. "The usual checks" means `npm run test:run`, `npm run lint` and `npx tsc --noEmit` exit 0 with every guard under `src/` green.

**Map slice (groups 7–11).** The view toggle, the map view, the card's map action, the full-screen map, the Locations tab's map, the `img-src` line of `proxy.ts` and the map texts use the map library Product owner approved on 2026-10-07 (design.md D16). Until group 9 the toolbar's view slot stays empty and no card renders a map action.
