# Tasks

Each group is a vertical slice; its heading names the commit scope. Tests are committed before the implementation they cover. Every verification step lists what must pass; "the usual checks" means `npm run test:run`, `npm run lint` and `npx tsc --noEmit` exit 0 and every guard under `src/` (`color-guard`, `radius-guard`, `focus-guard`, `badge-geometry-guard`, `xss-guard`, `client-boundary`, `icons`, `catalog-guard`, `theme-tokens`) is green.

**Map slice not tasked.** The view toggle, the map view, the card's map action, the full-screen map, the Locations tab's map, the `img-src` line of `proxy.ts` and the map texts (design.md D13, D14, D15 map parts) depend on the map library, which is a proposal pending Product owner (design.md D16). No task below installs or imports it; the architect adds the map slice here by an artifact update once Product owner approves it. Until then the toolbar's view slot stays empty and no card renders a map action.
